2. Data stored on your device

The App stores the following data locally on your device so that it's available the next time you open the App:

Backups. You can save your data to a file with Settings → Data → Export backup. The App then opens your device's share screen, and the file goes only where you choose to save or send it. The trash isn't included in this file. Import backup replaces the current data with a backup file you pick. Your device's own backup service (such as Google backup) may also include the App's data in your device backups, according to your device settings.

Error log. If the App runs into an unexpected error, it records the error on your device so that the problem can be found and fixed: the time, the error message (up to 300 characters), the place in the App's code where it happened, and the App version. Only the 20 most recent entries are kept. The log is meant for technical details only, but an error message may sometimes include part of what was being processed. The App never sends the error log anywhere, and it isn't included in backup files. You can copy it with Settings → About → Copy error log and, if you choose, send it to us yourself (for example by email). If you do, we use it only to find and fix the problem.
